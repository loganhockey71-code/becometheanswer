# Editing this site

This is a placeholder. The full plain-language guide (how to log into TinaCMS,
edit a page, add a Library entry, swap an image, and how the site deploys)
will be written in the final build phase, once every page and the Library CMS
collections exist.

For now: page content lives in `content/*.json`. The TinaCMS schema in
`tina/config.ts` describes the same fields and will drive the visual editor
once a TinaCloud project is connected.
